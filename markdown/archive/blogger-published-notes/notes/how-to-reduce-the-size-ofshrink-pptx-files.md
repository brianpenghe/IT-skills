1\. open the file 
2\. file -> export -> change file type 
3\. double click Power point picture presentation and save 

What you've saved is a file with all the elements compressed into pictures 

Alternatively, you may convert the pptx file into a pdf, extract pictures from the pdf and build a pptx on top of the pictures extracted.
