1\. Download the newest version of spotify here (if you are in the US) https://www.spotify.com/us/download/ 

2\. press alt + ctrl + delete to open task manager 

3\. there should be two processes running by spotify. End them two by clicking on them and end task 

4\. Now go to folder C:\\Users\\Brian\\AppData\\Roaming 
    and delete the Spotify folder to remove data 

5\. Install SpotifySetup.exe as usual
