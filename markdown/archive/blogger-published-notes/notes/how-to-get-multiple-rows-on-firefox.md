Getting multiple rows of tabs is really an efficient way for multi-tasking and cross-checking for intensive use of the browser. 

Here's how to do it: 

1\. Install Tab Mix Plus 
https://addons.mozilla.org/en-US/firefox/addon/tab-mix-plus/ 

2\. Restart and enable the it 
3\. Menu -> Preferences -> Tab Mix Plus Options -> Display -> When Tabs don't fit width -> Multiple Rows 

That's it.
