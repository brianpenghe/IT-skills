1\. log in your personal facebook account 
2\. in the search box type "youtube tab" and click in 
3\. Click install 
4\. in the box choose the page you want to add tab to 
5\. type in your youtube account information. Your ID can be found this way: 

http://troubleshoo.blogspot.com/2016/01/how-to-find-your-youtube-user-id.html 

6\. save the settings. That's done
