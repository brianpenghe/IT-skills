1\. Caltech IMSS recommends using the option 1, which is the Caltech-traffic-only option. It works, but not as well as another option when using a desktop in China. What I found was that using option 2 (all traffic) will have a 10 times-higher speed when downloading something from caltech box sync. 

2\. Talking about box sync, it is found that not only dropbox but also box sync has been blocked/restricted in China. Using the Caltech Box Sync will speed up the data transfer
