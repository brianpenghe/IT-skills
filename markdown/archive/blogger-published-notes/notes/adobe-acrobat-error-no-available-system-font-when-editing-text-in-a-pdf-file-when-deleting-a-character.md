I was trying to delete an extra period in the end of a paragraph using acrobat X but it said that the font isn't available.

So I followed this link [https://helpx.adobe.com/acrobat/kb/error-no-available-system-font.html#:~:text=Acrobat%209,Advanced%20Editing%20%3E%20TouchUp%20Text%20Tool.&text=In%20the%20TouchUp%20Properties%20dialog,current%20font%20you%20are%20using.](https://helpx.adobe.com/acrobat/kb/error-no-available-system-font.html#:~:text=Acrobat%209,Advanced%20Editing%20%3E%20TouchUp%20Text%20Tool.&text=In%20the%20TouchUp%20Properties%20dialog,current%20font%20you%20are%20using.)

although it was not so intuitive.

What I ended up doing was: highlight that extra period I wanted to delete then changed the color to white.
