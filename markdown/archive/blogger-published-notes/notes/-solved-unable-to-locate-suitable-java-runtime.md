Someone had an online answer which didn't work for me. i. e. download something here http://www.java.com/en/download/index.jsp 

What has worked is actually: 
1\. Go to this page http://www.oracle.com/technetwork/java/javase/downloads/jre8-downloads-2133155.html 
2\. accept the terms for downloading 8u65. For the difference between 8u65 and 8u66, you can check here http://stackoverflow.com/questions/33260616/whats-the-difference-between-java-8u65-and-8u66 

3\. Download and install the 8u65 for windows x64 if it matches 
4\. install your software (I was installing cytoscape)
