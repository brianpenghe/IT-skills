Take D501 as an example 

1\. Connect the external speaker to Mac 
2\. If there is a switch, switch the speaker to mp3 mode 
3\. On the Macbook, click the gear icon (System Preferences) , then Sound 
4\. Output tab -> Select USB rather than Built-in 
5\. Make sure the "Mute" box is unchecked
