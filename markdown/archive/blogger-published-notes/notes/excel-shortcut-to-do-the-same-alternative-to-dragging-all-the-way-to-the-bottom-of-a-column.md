(Double click the bottom right) 

To "Do the same", usually we have to drag the bottom right of a box all the way down/right to apply the same formula/pattern to the following cells. 

If a column/row is too long, that is not feasible. 
Therefore a shortcut is very necessary, which was mentioned in the first line of this blog --- Double click the bottom right of your box that you would have dragged.
