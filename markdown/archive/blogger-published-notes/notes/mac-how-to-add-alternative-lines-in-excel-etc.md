if you have a column 
36166 
19764 
37658 
36244 
29998 

How can you transform it to 
36166 

19764 

37658 

36244 

29998 

? 

The answer is using TextEdit. 

1\. Open TextEdit 
2\. Copy a line break (the part between the end of 36166 and the start of 19764) 
3\. command + f, paste the line break in the searching area, check replace 
4\. Paste the line break twice in the second box to replace one line break with two line breaks. In this way you will insert one line after each original line.  To get more line breaks, do the same.
