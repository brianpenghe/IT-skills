Dominion Online is a great game with multiple bugs, one of which is getting stuck in a previous game. 

If you get stuck, you are never going to be able to start a new game. Even if you restart or log on from a new browser you may still have this issue. 

Solution -- try all of these: 
1\. account -> log out 
2\. clear the browsing data 
3\. log onto the Japanese version of Dominion (日本语)
