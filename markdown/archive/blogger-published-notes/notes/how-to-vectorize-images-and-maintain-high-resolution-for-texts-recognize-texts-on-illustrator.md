copy paste / drag image onto Illustrator, 
then select that image object using selection tool 

Object(top bar) -> Flatten Transparency -> check convert All text to outlines -> OK 
Then do image trace (you either find the tools on top or Object -> Image trace), select low fidelity to let the software guess more or use high fidelity to respect the original image more. 
You may do Object -> Image trace -> expand to get individual patterns 

It might be needed to Rasterize the image before downstream processing
