# Skill: Create a Xiaohongshu (RedNote) Portfolio / Album

## Purpose

Document the workflow for creating a **Portfolio (Album)** in the
English version of Xiaohongshu (RedNote).

## Key Finding

The English UI uses inconsistent terminology.

  --------------------------------------------------------------------------
  English UI              Chinese Meaning                   Notes
  ----------------------- --------------------------------- ----------------
  Portfolio               合集                              Creator's
                                                            collection of
                                                            their own
                                                            published notes

  Create Album            创建合集                          Creates a new
                                                            Portfolio/合集

  Album Name              合集名称                          Title of the
                                                            portfolio

  Album Description       合集简介                          Optional
                                                            description

  Collection              收藏专辑                          Used for
                                                            organizing saved
                                                            posts, not your
                                                            own published
                                                            posts
  --------------------------------------------------------------------------

**Important:** Although the UI says **Album**, this feature corresponds
to the Chinese **合集** feature for organizing your own published notes.

------------------------------------------------------------------------

## How to Create a Portfolio (Album)

1.  Open **Profile**.
2.  Tap the **☰ (menu)** in the upper-right corner.
3.  Open **Creator Center**.
4.  Tap **Portfolio**.
5.  Tap **Create Album**.
6.  Fill in:
    -   **Album Name**
    -   **Album Description** (optional)
    -   Cover (if available)
7.  Create the album.
8.  Add your published notes to the album.

------------------------------------------------------------------------

## Expected Result

The Album appears on your profile as a curated series of your own posts,
allowing visitors to browse related notes together.

Typical uses include:

-   AI Tutorials
-   Research Tips
-   Bay Area Life
-   Travel Guides
-   Productivity
-   Food Reviews

------------------------------------------------------------------------

## UI Translation Notes

The English version currently mixes different terms:

-   Portfolio → feature/module
-   Create Album → action to create a portfolio
-   Album → the resulting portfolio
-   Collection → saved/favorited posts

This terminology is inconsistent, but **Portfolio/Create Album** is the
correct feature for creating creator collections (合集).
